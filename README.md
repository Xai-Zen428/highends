# Highends Auto Services website

Standalone React + Vite website mockup for Highends Auto Services Repairs and Services.

## Run locally

```sh
npm install
npm run dev
```

Open the Vite URL shown in the terminal. `npm run build` creates the production bundle in `dist/`.

The site uses React Router for the Home, About, Services, Repairs, Vehicle Brands and Contact pages. Styling uses Tailwind CSS v4's Vite integration alongside a small custom stylesheet. Lucide React supplies the interface icons.

## Notes

- Business details and listed hours follow the supplied verified information.
- The enquiry form is a front-end demonstration. It does not send or store submissions; contact the workshop by phone or email.
- The homepage hero includes a locally bundled vector workshop illustration so it displays without a network connection. Other automotive images are generic Unsplash stock images for layout illustration and are not represented as photos of the Highends workshop.
- The map is an embedded Google Maps query centred on the supplied street address.
- No social links are shown because an official account URL has not been verified.
